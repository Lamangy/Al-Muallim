# Al-Muallim: Arabisch Lernen mit Nagy Malek

![Al-Muallim App Banner](https://via.placeholder.com/1200x400?text=Al-Muallim+App+Preview)

**Al-Muallim** ist eine moderne, interaktive Web-App zum Lernen von Hocharabisch (Fusha). Sie wurde speziell entwickelt, um den Arabisch-Kurs von Herrn Nagy Abd El Malek an der VHS Hannover digital zu begleiten und zu erweitern.

Die App setzt auf haptisches, visuelles und auditives Lernen, um Buchstaben, Vokabeln und Grammatik effektiv zu vermitteln.

## 🌟 Features

### 📖 Lernen & Verstehen
*   **Strukturierte Lektionen:** Basierend auf dem originalen Kurs-Manuskript (Gruppen 1-9).
*   **Interaktive Karten:** Lernen Sie Buchstaben in all ihren Formen (Anfang, Mitte, Ende, Allein).
*   **Audio-Support:** Jeder Buchstabe und jedes Wort ist vertont (Hocharabisch).
*   **Grammatik-Häppchen:** Leicht verständliche Erklärungen zu Regeln wie Sonnen-/Mondbuchstaben oder der Femininendung.

### ✍️ Schreiben Üben
*   **Digitales Schreibheft:** Schreiben Sie arabische Buchstaben direkt auf dem Bildschirm (Touch & Maus).
*   **6-Linien-System:** Exakte Hilfslinien wie im Schulheft für die perfekte Kalligraphie.
*   **Hilfestellungen:** Ein- und ausblendbare Vorlagen zum Nachspuren.

### 🗣️ Sprechen & Aussprache
*   **KI-Trainer:** Sprechen Sie Wörter nach und erhalten Sie sofortiges Feedback.
*   **Fehleranalyse:** Die App zeigt Ihnen genau, welche Buchstaben Sie falsch ausgesprochen haben.
*   **Visuelles Feedback:** Farbliche Markierungen (Grün/Rot) für schnellen Lernerfolg.

### 🧩 Gamification & Spaß
*   **Verbindungs-Puzzle:** Lernen Sie spielerisch, wie sich Buchstaben verbinden.
*   **Story-Modus:** Chatten Sie mit Charakteren wie Nabil & Samira in interaktiven Dialogen.
*   **Fortschritt:** Sammeln Sie XP (Erfahrungspunkte), steigen Sie im Level auf und halten Sie Ihre Tages-Serie (Streak).

## 🚀 Technologie-Stack

Dieses Projekt wurde mit modernsten Web-Technologien gebaut, um schnell, responsive und zukunftssicher zu sein.

*   **Frontend:** [React 18](https://reactjs.org/) (mit Hooks & Functional Components)
*   **Sprache:** [TypeScript](https://www.typescriptlang.org/) (für Typsicherheit und bessere Wartbarkeit)
*   **Styling:** [Tailwind CSS](https://tailwindcss.com/) (für ein schönes, responsives Design)
*   **Icons:** [Lucide React](https://lucide.dev/)
*   **Audio:** Web Speech API (Native Browser TTS & STT) - **Keine externen API-Kosten!**
*   **Canvas:** HTML5 Canvas API für die Schreibübungen.

## 🛠️ Installation & Start

Du möchtest die App lokal auf deinem Computer laufen lassen?

1.  **Repository klonen:**
    ```bash
    git clone https://github.com/DEIN_USERNAME/al-muallim.git
    cd al-muallim
    ```

2.  **Abhängigkeiten installieren:**
    (Stelle sicher, dass du [Node.js](https://nodejs.org/) installiert hast)
    ```bash
    npm install
    ```

3.  **Entwicklungsserver starten:**
    ```bash
    npm start
    # oder
    npm run dev
    ```

4.  **App öffnen:**
    Besuche `http://localhost:3000` (oder den im Terminal angezeigten Port) in deinem Browser.

## 📱 Mobile Nutzung (PWA)

Die App ist als **Progressive Web App (PWA)** konzipiert.
Du kannst sie auf deinem Smartphone (Android & iOS) installieren, ohne den App Store zu nutzen:

1.  Öffne die gehostete Webseite (z.B. auf Netlify/Vercel) in Chrome oder Safari.
2.  Tippe auf "Teilen" (iOS) oder das Menü (Android).
3.  Wähle **"Zum Startbildschirm hinzufügen"**.
4.  Die App erscheint nun wie eine native App auf deinem Homescreen.
